# 終極預約 (Ultimate Appointments)

終極預約是 WooCommerce 的服務業預約外掛，讓芳療、SPA、美容美髮這類「時段即庫存」的服務業，用類似飯店控房的方式管理預約：
一個商品可設定多個服務方案（名稱／時長／價格），客人選方案、選服務人員、選時段後才加入購物車，
同一位人員同一個時段不會被重複賣出。

由 快捷鍵Ctrl+A（https://nibill-studio.com/）開發維護。

## 主要功能

- 預約商品與服務方案、指定或不指定服務人員
- 前台預約精靈（短代碼 [uappt_booking]，也可用 Elementor 拖拉）
- 人員管理：固定班／彈性班、每月班表、全店月排班表、班別設定（含顏色）
- 排班申請與審核、員工中心（我的班表、本月明細）
- 預約列表、日曆、今日營運、現場建單
- 報表、耗材管理、回訪管理
- 提醒通知（Email／LINE）

## 需求

- WordPress 6.0 以上、PHP 7.4 以上
- WooCommerce

## 名稱與代號

- 中文：終極預約；英文：Ultimate Appointments
- 外掛資料夾與文字網域：ultimate-appointments
- 程式前綴：UAPPT_／uappt_
- v3.0.0 以前的代號是 wc-service-booking／WCSB_／wcsb_，升級時資料會自動搬過來。
